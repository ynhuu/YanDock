## 1. 构建与启动

从 GitHub Release 交互安装并配置自启动，见[自动安装与卸载脚本](安装脚本.md)。该脚本需指定发布仓库，真实服务安装与各平台运行验收状态见该文档；以下为手动源码构建方式。

### 源码构建

准备以下环境：

- Go 1.25+。
- Node.js 22.12+（推荐 24）与 pnpm 11.22.0。
- 目标 Shell/CLI 及其运行依赖。
- 服务端 PATH 中可找到的 `git`，用于 Git 更改与差异功能。

在项目根目录执行，每一步成功后再继续：

```sh
pnpm --dir web install --frozen-lockfile
pnpm --dir web build
go build -o bin/yandock ./cmd/yandock
export YANDOCK_TOKEN="$(openssl rand -hex 32)"
./bin/yandock --dir .
```

访问 `http://127.0.0.1:8080`，使用自己设置的 `YANDOCK_TOKEN` 登录，点击“新建终端”。服务启动本身不创建终端进程。

网页在 Go 编译时嵌入：缺少前端构建产物时 Go 编译会失败；修改网页后必须重新构建前端、编译 Go 并重启，不能只刷新浏览器。构建好的二进制运行时不需要 Go、Node.js 或 pnpm，但仍依赖目标 Shell/CLI 及其工具。

### 启动参数

| 参数          | 默认值                      | 说明                                               |
| ------------- | --------------------------- | -------------------------------------------------- |
| `-v`          | 关闭                        | 显示构建版本并退出                                 |
| `--listen`    | `127.0.0.1:8080`            | HTTP 监听地址，远程访问需显式配置                  |
| `--program`   | 环境中的 `SHELL`，否则 `sh` | 通过 PATH 查找；部署时建议使用绝对路径             |
| `--dir`       | `.`                         | 所有新终端的初始目录，相对路径以服务启动目录为基准 |
| `--` 后的内容 | 无                          | 直接传给程序的参数列表，不拼接 Shell 字符串        |

```sh
./bin/yandock --program /absolute/path/to/program --dir /path/to/project -- argument1 argument2
```

所有终端共用这套启动配置，当前不能在网页中选择项目、程序或参数。通用启动入口不代表 Pi、OpenCode、Codex 的专用启动或恢复方式已验证。

运行 `./bin/yandock -v` 可查看版本；通过 Makefile 构建时可用 `VERSION=v1.2.3` 注入发布版本，默认显示 `dev`。

终端按 UTF-8 传输。若服务环境未使用 UTF-8 字符类别，YanDock 会为新终端进程设置平台适用的 UTF-8 `LC_CTYPE`；已有 UTF-8 locale 保持不变。

## 2. 访问凭据与登录

### 配置凭据

- 只读取启动环境中的 `YANDOCK_TOKEN`，不能为空，没有默认密码或强制复杂度。
- **程序不自动加载 `.env`，没有原生密码文件或网页改密入口。** 重启时需要重新注入凭据；使用原值沿用密码，使用新值更换密码。可选安装脚本会保存权限受限的密码文件，由启动脚本读取后注入环境，不改变程序接口。
- 服务读取后清除自身环境中的该变量，避免传给子终端；父 Shell 的环境不受影响。服务只保存摘要，不能取回原密码。
- 不在源码、文档、URL、启动参数或日志中写真实凭据。可被其他设备访问的部署应使用随机长凭据，并自行妥善保管。

### 最新成功登录有效

登录有效期为 12 小时。另一个设备或浏览器成功登录后，旧 Cookie 失效，旧终端连接被关闭；旧页面返回登录页，无终端连接的页面在下一次请求时发现失效。服务端终端进程继续运行，新设备可以连接现有会话，并恢复当前会话保留的最近输出；超出保留范围的更早画面不能恢复。

同一浏览器共享 Cookie 的标签页属于同一个登录，不会因打开标签页单独踢人。但每个终端仍只能有一个控制连接；重复连接会重试而不接管，需要关闭占用连接的旧页面。页面之间没有画面广播或列表实时同步。

主动退出只断开连接，不结束程序，也不显示异常登录警告。错误密码不会撤销当前登录。

### 登录限流

按整个服务的一分钟固定窗口计算，累计 5 次错误凭据后，后续登录返回 `429`。进入限制后正确凭据也暂时无法登录；窗口结束恢复，最多约 60 秒。成功登录不计入失败次数，也不清空已有失败计数。切换设备不能绕过。

## 3. 工作台与终端

### 创建、切换与关闭

- 每个终端独立运行程序，不设应用层总数量上限；实际容量受机器和浏览器资源限制。
- 普通屏幕在当前页面内保留最多 1,000 行回滚内容；刷新或卸载后该浏览器缓存清空，再通过服务端有界回放恢复最近内容。两种缓存的容量不同，不能保证恢复全部 1,000 行。
- 显示编号使用最小空闲正整数。显式关闭“终端 2”后可复用编号，其他终端不重排；自然退出的标签仍占用编号。
- Android 页面进入浏览器全屏（含 WebView 外壳隐藏系统栏和工具栏）时，工作台右上角显示本机 24 小时制时间（时:分）；普通页面、独立应用模式、iPhone 和其他平台不显示。
- 新标签按创建顺序追加，编号不代表顺序或唯一身份。切换保留各自实例、缓存与连接，后台标签也占用资源。
- 更多菜单中的“关闭当前终端”**不二次确认，会终止对应进程组**。进程自然退出只标为已结束，仍需显式关闭才能移除标签。

### 标签排序与键盘操作

- 长按标签约半秒后拖动排序，边缘停留可滚动；提前滑动只滚动标签栏。Escape 或手势取消不提交排序。
- 方向键、Home/End 可导航标签；Alt+左右方向键调整位置。排序不改编号、不切换当前终端、不重建连接。
- 排列只保留在当前页面，刷新或重新登录后恢复服务端创建顺序。
- 长按进入拖动状态时尝试短振动；iPhone/iPad Safari 等不支持或拒绝振动时静默跳过。
- 更多菜单支持键盘导航、Escape 关闭和焦点恢复。

### 状态与提示

| 状态或情况                               | 显示方式                                       |
| ---------------------------------------- | ---------------------------------------------- |
| 首次连接、正在关闭                       | 工作台统一显示蓝色状态卡片，底部标签栏仍可操作 |
| 自动重连                                 | 黄色状态卡片，连接期间暂停输入                 |
| 已连接                                   | 清除等待提示，底部标签显示状态并播报           |
| 进程结束、终端已移除、输入受阻或输出过快 | 黄色提醒卡片，通常 4 秒后消失                  |
| 上传进行中 / 上传或删除成功              | 蓝色进行中 / 绿色成功卡片                      |
| 部分上传成功后中断                       | 黄色提醒，显示已完成的数量                     |
| 请求失败、全部上传失败或协议不兼容       | 红色错误提示                                   |

普通断线重连使用持续的等待状态卡片，不重复生成临时提醒；终端模块尚未加载时也能显示连接提示。进程结束不等于成功退出，因此使用黄色提醒。

### 项目更改与文件

底部会话栏中“更多操作”旁的左箭头打开“Git / 文件”抽屉。手机和平板设备上面板全屏显示；其他设备靠右占视口的一半，点击外侧遮罩可关闭。设备类型按移动设备识别策略判断，不由浏览器窗口宽度决定。窄视口仍会隐藏文件大小等次要信息。面板跟随当前选中终端的工作目录；页面可见时，执行 `cd` 后约一秒内刷新目录和 Git 更改。没有选中终端时使用服务启动目录。后台页面暂停目录轮询，回到前台立即查询；也可使用面板刷新按钮。

“更改”按文件展开 Git 差异，显示汇总和单文件增删行数。文件行最右侧与文件树共用状态字母：`U` 为未跟踪、`A` 为新增、`M` 为修改、`D` 为删除；重命名、冲突等其他情况目前也使用 `M`，字母不代表完整的 Git 两列状态。展开后，文件标题在当前差异区域滚动时吸顶，可直接点击标题折叠；下方紧凑工具栏提供行数和“打开文件”入口。可同时展开多个文件，标题只在对应文件的内容范围内吸顶。统计受读取预算限制，未完成时明确显示提示，不能把零行当作准确结果。

“历史”显示当前目录 Git 仓库的提交分支线路、合并关系、分支和标签，首次读取 15 条；点击“加载更多历史”后每次追加 15 条，直到没有更多提交。点击提交可查看修改文件列表；继续点击修改文件可查看该提交与第一父提交之间的内容差异。文本文件使用差异视图，二进制文件显示不可文本化提示，超大文本显示截断提示和补丁；历史图只读，不提供 checkout、提交、推送或其他 Git 写操作。项目抽屉和 Git 视图菜单不使用 Escape 关闭，分别通过关闭按钮、外侧遮罩或再次点击选择器操作。

“文件”以可展开目录树浏览，常用操作如下：

| 操作 | 使用方式 |
| --- | --- |
| 预览文件 | 点击文本或图片文件；Markdown 使用文档排版，代码带语法高亮和行号，窄屏长行自动换行；图片支持 PNG、JPEG（`.jpg` / `.jpeg`）、GIF、WebP、ICO、SVG |
| 上传文件 | 上传按钮支持多选，客户端逐个提交；同名文件不会被覆盖，批量上传不保证整体成功 |
| 下载或删除文件 | 长按或右键普通文件，打开操作菜单；下载进度、完成状态和错误在工作台底部显示，可随时取消；同一文件重复下载会提示正在下载，不同文件可以并行下载 |
| 删除文件夹 | 长按或右键文件夹，在菜单中选择删除并确认 |
| 回到项目根目录 | 点击文件列表下方的空白区域 |

> **删除不可撤销**：删除文件夹会一并删除其全部内容，包括隐藏内容。

| 内容 | 当前上限 |
| --- | --- |
| 单个上传文件 | 10 MiB |
| 单个下载文件 | 128 MiB；超过限制时显示错误，不启动下载 |
| 文本预览 | 1 MiB；超过限制仍进入预览页并显示限制提示，可下载原文件；二进制或非 UTF-8 文件仅支持下载，不提供文本预览 |
| 图片预览 | 10 MiB；SVG 以图片方式加载，不执行脚本或加载外部资源；格式无效或浏览器无法解码时提示下载原文件 |
| Git 更改列表 | 2,000 项 |
| Git 提交历史 | 按 15 条分页加载，无累计条数上限 |
| 单次目录读取 | 5,000 个条目 |

列表达到上限时会显示截断提示。

文件预览中按系统或浏览器返回键，先回到文件列表，再按一次关闭抽屉；点击“文件列表”也可退出预览。直接关闭预览中的抽屉不会留下额外的返回层级。

文件夹长按或右键菜单还提供“上传”，选择的文件会上传到该文件夹，不受路径栏当前选中目录影响；顶部上传按钮仍使用当前选中目录。

默认隐藏点文件，可通过眼睛图标显示，切换终端时保留当前开关；`.git` 目录始终隐藏。符号链接不参与目录浏览。文件接口以当前终端目录为访问根，需登录且写入请求校验来源；这不构成终端命令的安全沙箱。

## 4. 外观、手机与平板

### 主题与字号

主题默认跟随系统。更多菜单中的主题按钮按“跟随系统 → 深色 → 浅色”轮换，并保存到当前浏览器。

“字体大小”使用 `−`、`+` 调整，范围 `8–16px`，每次 `2px`，默认 `14px`。所有终端及复制粘贴文本框共用当前字号；调整不重建连接。设置只保存在当前浏览器，不同设备各自独立。

### 辅助键与触摸滚动

Android、iPhone 和 iPad 显示辅助键栏；iPadOS 使用桌面 UA 时结合多点触摸识别。普通桌面不因窗口变窄或有触屏就启用移动交互。

按键从左到右为：

```text
显示 / 隐藏键盘 | Esc | Tab | Ctrl Shift | ↑ ↓ ← → ↵ | Ctrl+C Ctrl+D Ctrl+L | Home PgUp PgDn End
```

- 显示/隐藏键盘按钮固定在最左侧，不参与横向滑动；右侧其他按键保持单行，放得下时在剩余区域居中，窄屏可横向滑动。
- 按下辅助键时显示短暂的缩放反馈；支持 Vibration API 的设备会同步短震动。
- 仅移动端：轻点终端区域不会获取输入焦点、激活输入光标或向 CLI 发送点击操作；使用辅助栏最左侧按钮显示或隐藏软键盘。打开后可直接输入，辅助键操作不关闭键盘；终端输入框失焦后，按钮恢复为“显示键盘”。系统收起键盘时，即使输入框仍保持焦点，按钮也会在浏览器报告键盘或可视区域变化后切回“显示键盘”。桌面端仍可用鼠标点击终端并直接输入，不受这些限制影响。
- 单独的 Ctrl 为粘滞开关：下一次输入一个英文字母时转换为控制字符，然后关闭。
- Shift 为粘滞组合键：下一次辅助键会使用对应的 Shift 序列，输入单个英文字母时转换为大写，然后关闭。输入法及符号布局仍由系统键盘处理。
- Enter 发送回车（CR）。先点 Shift，再点 ↵，发送一次换行符（LF），随后 Shift 自动关闭。是否插入新行取决于当前 CLI 的按键绑定；Shell 可能将 CR 和 LF 都作为执行命令，不能用它保证只换行不执行。
- 方向键、Home 和 End 跟随程序的应用光标键模式：htop、vim 等全屏程序切换编码后辅助键同步切换，行为与键盘按键一致。
- 刷新页面或退出再登录后，通过有界回放恢复最近画面，并同步应用光标键、备用屏幕、鼠标报告和 bracketed paste 模式；更早内容及所有终端状态的完整恢复不在保证范围内。
- 普通终端滑动浏览本页缓存；全屏程序优先使用其支持的滚轮报告，触摸位移按终端行高换算为滚轮报告，否则回退翻页键。并非所有程序都支持滚动。
- 页面适配安全区和可视区域变化，限制缩放，不硬编码软键盘高度。

### 复制与粘贴（仅移动端）

长按终端约半秒，触点附近出现“复制 / 粘贴”悬浮菜单；提前滑动仍是滚动。点击外部关闭菜单或面板，滚动关闭菜单，切换终端清除面板。

**复制：** 选择“复制”，在只读文本框中用系统菜单选词、调整选区和拷贝，也可点“全选”。内容是长按时的可见屏幕快照，不随新输出变化；该面板没有发送按钮。

**粘贴：** 选择“粘贴”，点击空白输入框后长按，使用系统粘贴；检查或修改内容后点“发送”。

注意：

- **发送会在内容末尾额外附加一次回车，可能立即执行命令；原文换行也会保留。**
- 连接失败或发送缓冲不足时保留草稿，不单独发送回车；超过约 64 KiB 的内容应分批发送。
- 点击外部、取消或切换终端会丢弃未发送草稿；浏览器排队成功不等于服务端已确认接收，不自动重发。
- 终端区域屏蔽原生上下文菜单，文本框内保留系统选区与粘贴菜单。这里不调用 Clipboard API，因此局域网 HTTP 下也可通过系统菜单粘贴；系统操作仍受浏览器和设备策略影响。
- 桌面端使用 xterm 原有选择、快捷键和上下文交互，不启用这套面板。

Safari 可通过分享菜单“添加到主屏幕”。当前未提供 Chrome PWA manifest 或离线缓存。中文 IME、真实软键盘、系统复制粘贴菜单、触摸排序及 iOS WebGL 效果仍需真机验收。

## 5. 断线与恢复边界

| 场景                           | 服务端进程   | 终端画面                                 |
| ------------------------------ | ------------ | ---------------------------------------- |
| 切换本页终端标签               | 保留         | 保留当前实例和本页回滚缓存               |
| 网络断开再连接                 | 保留         | 回放最近输出并接续实时流，避免重复叠加   |
| 刷新、关闭页面后重开           | 保留         | 创建新实例，恢复会话最近保留的输出       |
| 退出登录、换设备或被新登录接管 | 保留         | 新登录可恢复会话最近保留的输出           |
| 进程自然退出                   | 已结束       | 记录保留期间仍可查看最后画面，不能再输入 |
| 显式移除终端                   | 终止并移除   | 清除该会话的保留输出                     |
| 服务重启                       | 清理当前会话 | 登录、会话及保留输出全部清除，不透明恢复 |

每会话最多保留 32 KiB 输出和 512 个数据/尺寸帧，只存服务器内存，不写入磁盘。输出可能包含命令回显和敏感信息；进程退出后仍保留至移除该终端，服务重启清除。超出范围会静默淘汰旧段，不弹出截断提醒。

恢复时会先清空浏览器中的旧画面，按历史尺寸重放，再适配当前视口；恢复完成前不发送输入。未截断时可以恢复普通终端及已验证的备用屏幕场景；截断后不能保证还原所有相对光标、颜色和全屏程序状态，也不恢复无限历史或终端图形内容。

自动重连采用 1–10 秒退避；网络恢复或页面回到前台时提前重试。同一登录重复连接不接管；若被另一个页面占用，需要关闭那个页面或连接。服务升级后若旧页面提示协议不兼容，请刷新页面。

## 6. 网络与部署

### 可信局域网 HTTP 测试

完成构建并设置凭据后，显式开放监听：

```sh
./bin/yandock --listen 0.0.0.0:8080 --dir .
```

其他设备访问 `http://开发机器的局域网IP:8080`。需要限制网卡时，可使用 `--listen 192.168.1.10:8080`，示例 IP 必须替换为实际地址。

防火墙需允许访问；访客 Wi-Fi、AP 隔离和不同子网可能阻断连接。`0.0.0.0` 不保证仅私网可达，不要配置公网端口转发。

**HTTP 不加密凭据、Cookie 和终端内容，只适合可信网络临时测试，不要用于公共 Wi-Fi 或公网。系统粘贴能用不代表传输安全。**

### HTTPS 反向代理

建议代理与服务同机，YanDock 保持回环监听：

```sh
./bin/yandock --listen 127.0.0.1:8080 --dir .
```

浏览器访问代理上的 HTTPS 域名。代理需要配置证书、HTTP 跳转、WebSocket 升级、请求大小与足够的空闲超时，并将原路径 `/`、`/api/` 转发到 YanDock。

- 保留浏览器的 Host（含非默认端口）和 Origin；来源不匹配会返回 `403`，不要关闭来源检查。
- 仅支持根路径部署，不承诺 `/yandock/` 等子路径。精确的 Origin 与 Cookie 规则见[终端协议](终端协议.md#1-认证与请求边界)。
- YanDock 本身没有证书参数，不依赖客户端提供的转发头判断来源。代理不在同机时，需额外保护后端链路并限制来源。
- 不暴露明文后端或 Vite 开发服务；不以 root 运行，不提供给不可信用户。当前尚未完成公网生产安全验收。

## 7. 更新、停止与重启

先构建新版本，确认成功后再停止旧服务。前台运行按 Ctrl+C；后台运行向**确认过身份的服务 PID**发送 SIGTERM，确认退出后再启动。不使用按名称批量杀进程的命令。

```sh
pnpm --dir web build
go build -o bin/yandock.next ./cmd/yandock
# 确认以上步骤成功，再停止原服务并等待其退出。
mv bin/yandock.next bin/yandock
# 在启动环境中重新提供 YANDOCK_TOKEN，并沿用原监听地址、程序、目录和参数。
./bin/yandock --dir .
```

示例是默认本机启动；局域网或自定义程序部署需保留原参数，代理部署同时保留外部代理配置。缺少凭据时服务拒绝启动。**重启会清理终端进程并要求重新登录，请先保存工作。**

Go 程序本身不安装后台服务。可选[安装脚本](安装脚本.md)可创建 launchd、systemd 或 OpenRC 配置，但不提供覆盖安装或自动升级；源码部署使用外部服务管理器时，应明确 PATH、工作目录和凭据环境。当前没有签名或公证流程。日志写入标准错误，落点由启动环境决定，不默认记录原始终端输入输出。

## 8. 常见问题

| 现象                           | 检查或处理                                                                                                                  |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| 缺少 `dist`，Go 无法编译       | 安装前端依赖后先执行 `pnpm --dir web build`                                                                                 |
| 找不到 CLI / 工作目录无效      | 核对 PATH、权限和 `--dir`；可用 `--program` 指定程序绝对路径                                                                |
| 密码不对或重启后不能登录       | 核对新进程注入的凭据；没有默认密码，不自动读取 `.env`                                                                       |
| 提示尝试过多                   | 等待当前一分钟窗口结束，不要不断重试                                                                                        |
| 被返回登录页                   | 检查新设备登录、登录到期、服务重启或 Cookie 失效                                                                            |
| 登录或 WebSocket 返回 `403`    | 核对地址、Origin、Host 和代理配置                                                                                           |
| 终端持续重连                   | 检查网络、服务存活及同登录其他页面的连接占用                                                                                |
| 已连接但画面空白               | 参见[恢复边界](#5-断线与恢复边界)，不要盲目重发命令                                                                         |
| 终端显示已结束                 | 自然退出不会删除标签；显式关闭后才释放编号                                                                                  |
| 网页仍是旧版                   | 前端构建后重新编译、重启 Go；旧分块失效时重新加载页面                                                                       |
| 新终端行首出现反白 `%`         | 可能是 zsh 行尾标记；新版已按实际网格创建。先更新并新建终端，仍复现时记录字号、窗口尺寸及 Shell 信息；不要过滤所有 `%` 输出 |
| 局域网 HTTP 无法一键读取剪贴板 | 移动端使用长按菜单中的文本框，再用系统粘贴；远程访问仍建议 HTTPS                                                            |
| 手机连不上                     | 使用开发机器的局域网 IP，不是手机的 `127.0.0.1`；检查防火墙和 Wi-Fi 隔离                                                    |

报告问题时提供平台/架构、浏览器、脱敏启动参数、步骤和错误信息；不要上传 Cookie、真实凭据、终端业务内容或完整环境变量。
